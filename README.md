# 检测与应对人工智能滥用

[Anthropic](https://www.anthropic.com) 于 2026 年 9 月 10 日发布的威胁情报报告
[*Detecting and countering misuse of AI*](https://www.anthropic.com)
简体中文网页阅读器。

在线阅读：<https://klarkxy.github.io/anthropic-ai-misuse-zh/>

## 功能

- 报告全文中文译本（网络、影响力、监视、常规武器、生物、诈骗、非法蒸馏）
- 目录、检索、字号、阅读进度
- 154 页英文原页对照
- 失陷指标可复制；英文原文 PDF 可下载

专有名称、GTG 编号、恶意软件名与失陷指标保留原文。

## 本地运行

```bash
npm install
npm run dev
```

GitHub Pages 静态构建：

```bash
npm run build:pages
```
